# hxwl-10 考古探方模型借用台

探方三维模型外借管理：按探方、地层、版本归档，借出脱敏、归还恢复、逾期管控。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- **模型归档**：按探方、地层、版本登记三维模型，记录控制点与精确坐标点数
- **控制点独占校验**：控制点被其他探方占用时，指出占用方并拦住提交
- **借出登记**：登记借用单位、用途、保管人、到期日；借出时保留原模型，自动生成移除精确坐标的脱敏副本
- **归还恢复**：办理归还后，档案版本恢复至借出前版本，并记录对方交回版本
- **逾期管控**：到期未还自动标记逾期，逾期模型禁止再次借出
- **本地持久化**：借出、脱敏副本、归还结果存入 localStorage，重开页面可查到
