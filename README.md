# hxwl-10 考古探方模型借用台

遗址探方三维模型的归档、外借脱敏与归还版本管理

## 技术栈

React + Vite + TypeScript + CSS（本地状态，localStorage 持久化）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- **模型归档**：按探方、地层/遗迹单位、版本登记三维模型与控制点
- **控制点占用校验**：一个控制点已被其他探方占用时，指出占用方并拦截提交（同探方共用不拦截）
- **借出脱敏**：借出时原模型保留封存，自动生成移除精确 E/N/高程坐标、仅保留相对偏移的脱敏副本；登记借用单位、用途、保管人和到期日
- **逾期拦截**：逾期未还的模型不能再次借出，也不能重复借出未归还的模型
- **归还回退**：归还后模型恢复到借出前封存版本（即使借出期间档案升过版本），并写明归还结果
- **台账可查**：借出记录、脱敏副本编号与归还结果持久化保存，重开页面仍可按"借出中 / 逾期未还 / 已归还"筛选查询
